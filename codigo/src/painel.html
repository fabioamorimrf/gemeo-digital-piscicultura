      Controle pelo celular

      Para controlar pelo celular, o site precisa estar hospedado (GitHub Pages, por exemplo) ou aberto pelo servidor.py. Aberto direto do arquivo, o celular não consegue acessar a página.

      O computador e o celular trocam mensagens por um broker MQTT na internet, com um código de sala só desta apresentação.

      Usuário e senha (só se o broker pedir)

      Use uma credencial só para a demo: ela vai junto no QR code e fica visível no navegador.

      Aponte a câmera do celular para o código. A simulação passa para o celular sem perder o estado, e este painel continua mostrando tudo.

      Simulador nesta aba

      Para apresentar com duas telas, use "Abrir o simulador": a simulação passa para a outra aba sem perder o estado.
